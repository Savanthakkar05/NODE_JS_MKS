✅ What is Socket.IO?
Socket.IO is a JavaScript library (for both client and server) that enables real-time, bi-directional communication between web clients (like browsers) and servers.

It uses WebSockets under the hood but provides additional features like fallback support (e.g., polling), event-based communication, automatic reconnection, and rooms/namespaces.

Works with Node.js on the backend and in the browser on the frontend.

✅ Why do we use Socket.IO?

We use Socket.IO when we need instant data exchange without reloading the page. Typical use cases include:

| Use Case                      	| Why Socket.IO is Ideal                         		|
| -------------------------------	| ---------------------------------------------- -------	|
| 💬 Chat apps               	| Send/receive messages instantly                	|
| 📊 Live dashboards     	| Show real-time metrics, stock updates, etc.    	|
| 🕹️ Online multiplayer games 	| Sync player movements or actions in real-time  	|
| 🔴 Live notifications        	| Push alerts/updates to the browser immediately 	|
| 👨‍💻 Collaborative tools    	| Real-time doc editing, whiteboards, etc.       	|

✅ Difference between HTTP and Socket.IO (WebSocket)

| Feature		| **HTTP**                                   			| **Socket.IO / WebSocket**                 	|
| --------------------	| ------------------------------------------ -----------	| ----------------------------------------- 	|
| Protocol   	| Request-response (client initiates only)   		| Full-duplex (bi-directional)              	|
| Connection 	| Short-lived (each request opens a new one) 	| Long-lived (persistent connection)       	|
| Real-time  	| ❌ No (needs polling or long-polling)       	| ✅ Yes (real-time updates)                	|
| Data Flow  	| Client → Server only (mostly)              		| Client ⇄ Server (both ways)               	|
| Use Cases  	| Static websites, form submissions, APIs    	| Live chat, real-time games, notifications 	|
| Latency    	| Higher (due to repeated handshakes)        	| Lower (once connection is open)           	|

🔌 1. Connection
Establish a real-time connection between client and server.

Server Side:
io.on('connection', (socket) => {
    console.log('A user connected:', socket.id);
});

Client Side:
const socket = io();  // connects to the server automatically


📡 2. Emitting and Listening to Events
Allows sending and receiving custom events between client and server.

Client → Server:
socket.emit('myEvent', { message: "Hello Server!" });
Server listens:
socket.on('myEvent', (data) => {
    console.log(data.message);
});

Server → Client:
socket.emit('serverMsg', 'Hello Client!');
Client listens:
socket.on('serverMsg', (msg) => {
    console.log(msg);
});


💬 3. Broadcasting
Send a message to all clients except the sender.
socket.broadcast.emit('user-joined', username);


🏠 4. Rooms
Group sockets together so you can send messages only to members of a specific room.

socket.join('room1'); // join room
io.to('room1').emit('msg', 'Hello Room Members'); // send to room


🧩 5. Namespaces
Create separate communication channels on the same Socket.IO server.

const chatNamespace = io.of('/chat');
chatNamespace.on('connection', (socket) => {
    console.log('Connected to /chat namespace');
});
On client:
const socket = io('/chat');


🧠 6. Middleware
Run logic before a socket is allowed to connect (like auth).

io.use((socket, next) => {
    const token = socket.handshake.auth.token;
    if (isValid(token)) {
        next();
    } else {
        next(new Error("Authentication error"));
    }
});


⚠️ 7. Error Handling
Listen for errors and handle them safely.

socket.on('connect_error', (err) => {
    console.log('Connection error:', err.message);
});


🔁 8. Reconnection Strategies
Socket.IO supports automatic reconnection if the connection drops.

const socket = io({
    reconnectionAttempts: 5,
    reconnectionDelay: 1000,
});


📜 9. Acknowledgements
Receive confirmation when a message is delivered.

// Client
socket.emit('send-message', 'Hello', (response) => {
    console.log('Server responded:', response);
});

// Server
socket.on('send-message', (msg, callback) => {
    console.log(msg);
    callback('Message received');
});


🧑‍🤝‍🧑 10. Get All Clients in a Room
Useful for listing members in a chat room.

const clients = await io.in('room1').allSockets();
console.log(clients.size); // number of users

✅ 🔄 Expressions, What They Return, and How to Use Them

| **Expression**                          		| **Returns**                         		| **Description**                                                            			|
| ------------------------------------------ 	| ------------------------------------------ 	| -------------------------------------------------------------------------- 	|
| `io.sockets.adapter.rooms`              	| `Map<roomName, Set<socketIds>>`     	| All active rooms (including socket private rooms).                         	|
| `io.sockets.adapter.rooms.size`         	| `Number`                            		| Total number of rooms (private + custom).                                  	|
| `io.sockets.adapter.sids`               	| `Map<socketId, Set<roomNames>>`     	| Maps each socket ID to the rooms it has joined.                            	|
| `socket.rooms`                          		| `Set<roomNames>`                    	| Set of rooms that this socket is currently in (includes its private room). 	|
| `io.in(roomName).allSockets()`          	| `Promise<Set<socketIds>>`           	| Gets all sockets connected to a specific room (async).                     	|
| `socket.join(roomName)`                 	| `void`                              		| Adds a socket to a room.                                                   		|
| `socket.leave(roomName)`                	| `void`                              		| Removes a socket from a room.                                              		|
| `io.to(roomName).emit(...)`             	| `void`                              		| Emits an event to all sockets in a specific room.                          	|
| `socket.id`                             		| `string`                            		| Unique ID of the socket (used as a private room).                          	|
| `Array.from(io.sockets.sockets.keys())` 	| `Array<string>`                     		| All connected socket IDs.                                                  		|
| `Array.from(socket.rooms)`              	| `Array<string>`                     		| List of room names that the socket is in.                                  		|
| `Object.keys(io.sockets.adapter.rooms)` 	| (⚠️ older versions) `Array<string>` 	| List of all room names (deprecated in v4+ in favor of `.rooms` Map).       	|


📘 Example Breakdown with Explanations


🔹 Get All Rooms (including socket private rooms)

---> const rooms = io.sockets.adapter.rooms;
for (const [roomName, socketSet] of rooms) {
    console.log(`Room: ${roomName}, Members: ${socketSet.size}`);
}

🔹 Get Only Custom Rooms (exclude private socket IDs)

---> const customRooms = [];

const rooms = io.sockets.adapter.rooms;
const sids = io.sockets.adapter.sids;

for (let [roomName, socketsSet] of rooms) {
    if (!sids.has(roomName)) {
        customRooms.push(roomName);
    }
}
console.log('Custom Rooms:', customRooms);

🔹 Get Number of Custom Rooms

---> let customRoomCount = 0;
for (let [room, sockets] of io.sockets.adapter.rooms) {
    if (!io.sockets.adapter.sids.has(room)) {
        customRoomCount++;
    }
}
console.log('Total custom rooms:', customRoomCount);

🔹 Get All Sockets in a Room (Async)

---> io.in('room1').allSockets().then((sockets) => {
    console.log(`Users in room1: ${sockets.size}`);
    console.log(Array.from(sockets)); // list of socket IDs
});

🔹 Get Rooms of a Specific Socket

---> io.on('connection', (socket) => {
    console.log(Array.from(socket.rooms)); // includes [socket.id, ...joinedRooms]
});

📡 What is Broadcasting in Socket.IO?
Broadcasting means sending a message from one socket to other sockets — not just one specific client.

It allows you to notify:

--> All clients,

--> All except the sender,

--> Clients in a specific room,

--> Clients in a specific namespace.


✅ Types of Broadcasting

| **Type**                              		| **Meaning**                                    		| **Example**                        		|
| ------------------------------------------	| -----------------------------------------------------	| ------------------------------------------	|
| Broadcast to **all**                  		| Every connected client                         		| `io.emit()`                        		|
| Broadcast to **all except sender**    	| Everyone except the socket that sent the event 	| `socket.broadcast.emit()`          		|
| Broadcast to a **room**               	| All sockets in a specific room                 		| `io.to('room1').emit()`            		|
| Broadcast to a **room except sender** 	| Others in the room, except sender              	| `socket.to('room1').emit()`        		|
| Broadcast to **multiple rooms**       	| All sockets in multiple rooms                  		| `io.to(['room1', 'room2']).emit()` 	|
| Broadcast to a **namespace**          	| Sockets in a specific namespace only           	| `io.of('/chat').emit()`            		|



📘 Code Examples

🔹 1. Broadcast to All Clients

---> io.emit('server-message', 'This is for everyone!');

🔹 2. Broadcast to Everyone Except Sender

---> io.on('connection', (socket) => {
    socket.on('send-message', (data) => {
        socket.broadcast.emit('receive-message', data);
    });
});

🔹 3. Broadcast to a Specific Room

---> io.to('room1').emit('receive-message', 'Hello Room 1');

🔹 4. Broadcast to a Room Except the Sender

---> socket.to('room1').emit('receive-message', 'User joined Room 1');

🔹 5. Broadcast to Multiple Rooms

---> io.to(['room1', 'room2']).emit('announcement', 'Message to multiple rooms');

🔹 6. Broadcast in a Namespace

---> const chatNamespace = io.of('/chat');

chatNamespace.emit('chat-notify', 'New user joined chat namespace');

🔄 Summary Cheat Sheet

| **Command**                  	| **Who Receives**          	|
| -------------------------------	| -------------------------------	|
| `io.emit()`                  	| Everyone                  	|
| `socket.broadcast.emit()`    	| Everyone except sender    	|
| `io.to('room').emit()`       	| All in room               	|
| `socket.to('room').emit()`   	| All in room except sender 	|
| `io.of('/namespace').emit()` 	| All in namespace          	|
